# FastAPI Basic Backend

A lightweight, RESTful FastAPI backend demonstrating basic endpoint creation, path parameters, and query parameters. This project uses [`uv`](https://github.com/astral-sh/uv) for fast Python package management.

## Prerequisites

- Python 3.10+
- [uv](https://docs.astral.sh/uv/) installed on your system

## Installation & Setup

1. **Initialize the project** (if you haven't already):

   uv init
